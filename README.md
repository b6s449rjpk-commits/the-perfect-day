# 🌼 The Perfect Day

A soft, pastel reflection website where you roll a dice to get random journaling prompts. 
All your answers are saved like a diary in your browser.

**Live Demo**: `https://your-username.github.io/the-perfect-day/`

---

### ✨ Features
- 🎲 **Random Dice Questions** - Never run out of things to reflect on
- 📖 **Personal Diary** - Answers save automatically with date + time using localStorage
- 🌸 **Pastel & Soft Theme** - Calming gradient + cozy UI
- 💻 **No Backend Needed** - 100% HTML, CSS, JavaScript. Works offline
- 🔒 **Private** - All your diary entries stay in your own browser

### 📝 How to Use
1. Click `🎲 Roll` to get a reflection question
2. Write your thoughts in the box
3. Click `Save to Diary`
4. Scroll down to see all your past entries

### 🛠️ Tech Stack
- **HTML5** - Structure
- **CSS3** - Pastel styling + gradients
- **Vanilla JavaScript** - Dice logic + localStorage
